# Hot 100 速通刷题 Skill

> 本 Skill 适用于 `hot100-speedrun.md` 计划，聚焦 LeetCode Hot 100 的**阶段式刷题**执行。

## 📌 Skill 定位

本Skill是**刷题执行层**的引导文件，与 `docs/plans/hot100-speedrun.md`（数据层）和 `.clinerules`（操作层）配合使用：

| 层级 | 文件 | 职责 |
|------|------|------|
| 操作层 | `.clinerules` | 文件路径、命名、Javadoc规范、持久化流程 |
| 数据层 | `docs/plans/hot100-speedrun.md` | 计划表、评级、回顾轮次、进度 |
| **执行层** | **本 Skill** | **阶段刷题策略、每日节奏、认知工具** |

---

## 🧭 阶段刷题策略

Hot 100 按**分块**顺序推进，每块内部按编号顺序刷。块间顺序也是固定的（见计划表）。

### 当前块顺序

```
①哈希 → ②双指针 → ③滑动窗口&子串 → ④普通数组 → ⑤矩阵
→ ⑥链表 → ⑦二叉树 → ⑧图论&Trie → ⑨回溯 → ⑩二分搜索
→ ⑪栈&单调栈 → ⑫堆 → ⑬贪心 → ⑭一维DP → ⑮多维DP → ⑯技巧
```

### 阶段节奏

| 阶段 | 聚焦 | 每日题量 |
|------|------|---------|
| 🔵 新题阶段 | 按分块顺序刷未 A 的题 | 3~5 道 |
| 🟡 回顾阶段 | 处理 R1/R2/R3/R4 到期的回顾 | 全量处理 |
| 🟢 混合模式 | 回顾 + 新题混合 | 回顾全量 + 新题 3~4 道 |

## 📋 每日执行流程

### 第 1 步：检查回顾

读取 `hot100-speedrun.md` 的总进度表，按以下规则计算**回顾到期数**：

```
R1 到期日 = 首刷日 + 1 天
R2 到期日 = 首刷日 + 3 天
R3 到期日 = 首刷日 + 7 天
R4 到期日 = 首刷日 + 30 天
```

- 当前日期 >= 到期日 且 对应轮次标记为 `□` → **回顾到期**
- 回顾到期数必须准确反映到计划表的"回顾到期"指标中

### 第 2 步：处理回顾

- 列出所有到期回顾题 → 询问用户是否还记得
- 用户说「记得/会了/做烂了」→ 直接标记 ✅
- 用户说「不记得/写不出」→ 该题降为 ⬜，重刷

### 第 3 步：推进新题

回顾处理完后，按计划表顺序推进未 A 的下一题：

1. 在 Solution.java 放题（完整 Javadoc + main 方法测试）
2. 用户写代码
3. 用户通知 AI 评审
4. AI 编译运行验证（mvn compile exec:java 运行 main 方法）
5. 通过 → A 级，迁移题解，更新计划
6. 未通过 → 给提示，用户修改后重试

### 第 4 步：更新计划

每道题完成时必须更新 `hot100-speedrun.md`：
- 评级列
- 首刷日
- 回顾轮次标记
- 分块进度
- 总进度

## 🧠 认知工具

### 核心套路速查（按块）

| 块 | 核心套路 |
|----|---------|
| ① 哈希 | HashMap / HashSet |
| ② 双指针 | 左右夹逼/快慢指针 |
| ③ 滑动窗口 | 定长/int[26] / 可变/计数 |
| ④ 普通数组 | 前缀和/原地哈希/Kadane |
| ⑤ 矩阵 | 边界收缩/转置/右上角 |
| ⑥ 链表 | 快慢指针/dummy头/递归 |
| ⑦ 二叉树 | 递归/BFS/中序/前缀和 |
| ⑧ 图论 | DFS沉岛/多源BFS/拓扑/Trie |
| ⑨ 回溯 | 组合/排列/剪枝/方向 |
| ⑩ 二分搜索 | 左右边界/有序段/第k小 |
| ⑪ 栈 | 匹配/单调栈/双栈 |
| ⑫ 堆 | 大小堆/快速选择/桶排序 |
| ⑬ 贪心 | 局部最优/最远可达 |
| ⑭ DP一维 | 状态转移/完全背包/0-1背包 |
| ⑮ DP多维 | 网格DP/中心扩展/编辑距离 |
| ⑯ 技巧 | 异或/投票/三指针 |
