## 核心心法

### 1. 用"标记"代替"辅助数组"

当你需要记录哪些行/列要操作时，**不要新建数组**——用矩阵本身的边缘作为标记区。

| | 错误倾向 | 正确做法 |
|--|---------|---------|
| LC73 矩阵置零 | 用两个 `Set<Integer>` 存要置零的行和列 | **用第一行第一列做标记**，额外仅需 2 个 `boolean` |
| 通用原则 | O(m+n) 额外空间 | **O(1)** 额外空间 |

**手法：** 先把边缘的原始信息存到变量里 → 复用边缘做标记 → 最后用变量恢复边缘。

### 2. 用"边界指针"管理遍历

| | 错误倾向 | 正确做法 |
|--|---------|---------|
| LC54 螺旋矩阵 | 用公式算还剩多少元素 | 维护 **top/bottom/left/right** 四个指针 |
| LC48 旋转图像 | 试图一步到位算旋转后的坐标 | 拆成两步：**先转置，再水平翻转** |

**本质：** 矩阵上的路径/交换问题，**边界的演变是一个过程，不是一个公式**。四个指针各自只管一条边，状态一目了然。

### 3. 统一视角

三道题都要求**原地操作（O(1)额外空间）**，核心手法是把信息**编码到矩阵自身已有的位置**里：

- **LC73** → 编码到第一行第一列（标记法）
- **LC54** → 编码到四个边界指针（收缩法）
- **LC48** → 编码到两步交换顺序（转置→反转）

**一句话记住：** 想省空间，就利用矩阵本身的边缘/对角线存信息，别新开容器。
