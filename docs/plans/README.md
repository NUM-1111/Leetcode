# LeetCode 刷题计划目录

## 📌 声明

本项目遵循 **唯一计划**：`hot100-speedrun.md`

任何时候 AI Agent 在生成今日任务、分析回顾、推断进度时，**只参考这一个文件**。不存在多套计划并行的情况。

## 📋 Agent 行为守则

### 1. 计划唯一性

- `hot100-speedrun.md` 是本项目**唯一的刷题计划文件**
- 禁止 AI 自行脑补、推测或创造不在该文件内的新题/新计划
- 只在 `docs/plans/` 目录下读写与该计划相关的文件

### 2. 回顾规则

- 回顾到期数 = 计划表中所有 `R1=R2=R3=R4` 列标记为 `□` 且对应的天数已到的题数总和
- 计算规则：
  - R1：首刷日 + 1 天
  - R2：首刷日 + 3 天
  - R3：首刷日 + 7 天
  - R4：首刷日 + 30 天
- 用户回答「昨天做过了/已经会了」→ AI 直接标记对应轮次为 ✅ 并更新历史回顾记录
- 不要在回顾问题上和用户反复确认

### 3. 持久化流程

每道题从开始到结束的完整流程是：

```
用户要求刷某题
    ↓
AI 在 Solution.java 放置题目（含完整 Javadoc 描述）
    ↓
用户写代码
    ↓
用户写完后通知 AI 评审
    ↓
AI 编译运行测试
    ↓
通过 → 评 A 级，迁移到 LC{题号}_{题目名}.java
未通过 → 给提示，用户修改后重试
    ↓
AI 更新 hot100-speedrun.md（评级、首刷日、轮次标记、进度）
```

### 4. 养成模式

- 放题到 Solution.java 时：Javadoc 中必须包含**完整题目描述、示例、约束、核心套路**
- 迁移到 LC{题号}_{题目名}.java 时：保留完整 Javadoc 描述
- 不允许使用简写或省略号截断 Javadoc

### 5. 今日任务格式

AI 生成今日任务时必须包含：

1. **回顾检查**：计算回顾到期数，列出具体题号和轮次
2. **主任务**：当前正在刷的题（如果有）
3. **新题清单**：计划推进的下一批题目（与计划表顺序一致）
